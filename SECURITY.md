# Security Policy

## Supported versions

This project is currently pre-1.0. Until the first stable release, security
fixes are applied to the latest published version only. Once 1.0 is released,
the most recent 1.x line will receive security updates.

## Reporting a vulnerability

Please report security vulnerabilities privately rather than opening a public
issue. You can:

- Email **matt@suhock.net**, or
- Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  on the repository.

Please include enough detail to reproduce the issue, such as affected versions,
a description of the impact, and any proof-of-concept code.

## What to expect

- We will acknowledge your report after receiving it.
- We will investigate, keep you informed of progress, and work toward a fix.
- We follow coordinated disclosure: please give us a reasonable opportunity to
  release a fix before any public disclosure.

Thank you for helping keep the project and its users safe.
